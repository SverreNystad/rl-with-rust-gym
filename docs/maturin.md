# Maturin

To create a new project with maturin, run the following command:
```bash
maturin new --src --mixed --bindings pyo3 --name rl_with_rust_gym rl_with_rust_gym
```

To build the project, run:
```bash
maturin build
```

To install the project in development mode, run:
```bash
maturin develop
```
